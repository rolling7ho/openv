GTA V mods stopped working (OpenV fix)

When to use this: GTA V has updated and Menyoo (F8) no longer opens. This procedure teaches
OpenV the new game version. It is required only after a game update.

How to run it

1. Quit GTA V if it is running (save first if you are playing).
2. Open Finder and navigate to Desktop > vodka > OpenV.
3. Double-click "Rebuild OpenV Map". A Terminal window opens. Press any key to start.
4. If Vodka asks "Launch Grand Theft Auto V Enhanced?", click Launch.
5. If GTA displays a message about graphics drivers, click OK.
6. Do not interact with the game. It opens and closes by itself.
7. Wait approximately 20 minutes. The Terminal window may appear inactive during "Step 4";
   this is expected.
8. When the run finishes, the result is displayed with a short explanation. Press any key to
   close the window.

Without Finder, paste the following into the Terminal application and press Return:

~/Desktop/vodka/OpenV/Rebuild\ OpenV\ Map.command

Result meanings

- DONE: Mods should work again. Start GTA from Vodka. In story mode, press F8 (twice on the
  first attempt).
- UP TO DATE: The map already matches this game version, so the cause is elsewhere. Usually
  Menyoo itself requires an update.
- FAILED, game closed or crashed while loading: GTA sometimes crashes during startup. Run
  the procedure again.
- FAILED, could not read the running game: Quit GTA, quit and reopen Vodka, then run the
  procedure again.
- FAILED, update too large or unreliable: The automatic fix cannot handle this update.
  GTA still runs, without mods. Wait for a newer OpenV or ScriptHookV.

Notes

- The procedure does not damage the game. If a step fails, nothing is changed and mods
  remain disabled.
- The first run may install a small analysis tool, which requires an internet connection. If
  macOS offers to install "command line developer tools", click Install, wait, then run the
  procedure again.
- Details of each run are written to Desktop > vodka > OpenV > rebuild-map.log.
- Single-player only. OpenV closes GTA if it detects GTA Online.
